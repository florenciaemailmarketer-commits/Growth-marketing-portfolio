# Growth-marketing-portfolio
## Tools Installed
- Cursor IDE — downloaded and installed from cursor.com
- GitHub account created at github.com
- Repository cloned locally using Git via Terminal

## Steps Completed
1. Downloaded and installed Cursor IDE
2. Created a GitHub account and a public repository
3. Attempted to install Claude Code as a Cursor extension as instructed — extension not found
4. Researched and discovered Claude Code is a separate CLI tool, not a Cursor extension
5. Installed Git command line tools on Mac
6. Cloned the repository locally using Terminal
7. Opened the repository in Cursor editor

## Issues I Ran Into
- Claude Code does not exist as a Cursor extension. After researching online, I found it is a standalone CLI tool separate from Cursor.
- Terminal did not have permission to access the Documents folder. Solved by enabling Full Disk Access in System Settings > Privacy & Security.
- The repository folder was not visible in Cursor's file picker at first. Solved by cloning the repo directly to the home folder via Terminal.

## How I Solved Them
- Searched online to verify Claude Code installation method
- Granted Terminal full disk access in Mac system settings
- Used git clone command in Terminal to download the repository locally
